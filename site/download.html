Windows

  1. Descarga the_river_client_windows.zip y descomprímelo en una carpeta tuya.
  2. Download the_river_client_windows.zip and extract it into a folder of your own.
  3. Crea tor_data\runtime.env junto al ejecutable (ver Configuración).
  4. Create tor_data\runtime.env next to the executable (see Configuration).
  5. Ejecuta the_river_client.exe. El cliente arranca su propio Tor si no hay uno en 127.0.0.1:9050.
  6. Run the_river_client.exe. The client starts its own Tor if none is listening on 127.0.0.1:9050.

O todo de una vez en PowerShell:

Or all at once in PowerShell:

New-Item -ItemType Directory -Force -Path "$HOME\TheRiverChat" | Out-Null
cd "$HOME\TheRiverChat"
Invoke-WebRequest -Uri "https://github.com/jhulio435m/the_river/releases/latest/download/the_river_client_windows.zip" -OutFile client.zip
Expand-Archive -Path client.zip -DestinationPath . -Force
New-Item -ItemType Directory -Force -Path tor_data | Out-Null
"THE_RIVER_ONION=<tu-direccion>.onion" | Out-File -FilePath tor_data\runtime.env -Encoding ascii
.\the_river_client.exe

Linux

  1. Descarga the_river_client_linux.zip y descomprímelo.
  2. Download the_river_client_linux.zip and extract it.
  3. Da permisos de ejecución a the_river_client y tor_bin/tor.
  4. Make the_river_client and tor_bin/tor executable.
  5. Crea tor_data/runtime.env y ejecuta ./the_river_client.
  6. Create tor_data/runtime.env and run ./the_river_client.
mkdir -p ~/TheRiverChat && cd ~/TheRiverChat
wget -L https://github.com/jhulio435m/the_river/releases/latest/download/the_river_client_linux.zip
unzip -o the_river_client_linux.zip
chmod +x the_river_client tor_bin/tor
mkdir -p tor_data
printf 'THE_RIVER_ONION=%s\n' '<tu-direccion>.onion' > tor_data/runtime.env
./the_river_client

Si faltan librerías del sistema, instala GLFW, OpenGL y OpenSSL 3 (en Debian/Ubuntu: libglfw3, libgl1, libssl3).

If system libraries are missing, install GLFW, OpenGL and OpenSSL 3 (on Debian/Ubuntu: libglfw3, libgl1, libssl3).

Termux (Android)

El cliente corre dentro de Termux:X11 con una vista compacta (panel de usuarios plegable, adjuntos con un toque). Necesitas Termux, la app Android Termux:X11 (release nightly oficial), termux-x11-nightly, termux-api y tor.

The client runs inside Termux:X11 with a compact layout (collapsible users panel, one-tap attachments). You need Termux, the Termux:X11 Android app (official nightly release), termux-x11-nightly, termux-api and tor.

pkg install git
git clone https://github.com/jhulio435m/the_river
cd the_river/the_river_cpp
bash scripts/install_termux_dependencies.sh
mkdir -p tor_data
printf 'THE_RIVER_ONION=%s\n' '<tu-direccion>.onion' > tor_data/runtime.env
bash scripts/run_termux_client.sh --rebuild --start-tor

  • On Termux the binary does not launch Tor itself: pass --start-tor or run tor --SocksPort 9050 in another session before the client.
  • Los archivos se eligen con termux-storage-get y se abren con termux-open (por eso hace falta termux-api).
  • Files are picked with termux-storage-get and opened with termux-open (hence termux-api).
  • Para recompilar a mano: bash scripts/build_client_termux.sh.
  • To rebuild by hand: bash scripts/build_client_termux.sh.

Configuración del clienteClient configuration

El cliente lee variables de entorno y, si no existen, el primer archivo que encuentre entre tor_data/runtime.env y .env.local (en la carpeta actual o junto al ejecutable). Con protocolo 2 basta con esto:

The client reads environment variables and, failing that, the first file it finds among tor_data/runtime.env and .env.local (in the current folder or next to the executable). With protocol 2 this is all it needs:

# tor_data/runtime.env
THE_RIVER_ONION=<tu-direccion>.onion

Opcional: THE_RIVER_CLIENT_LOG=1 escribe client_runtime.log para diagnóstico (nunca incluye mensajes ni credenciales). Más opciones en la guía.

Optional: THE_RIVER_CLIENT_LOG=1 writes client_runtime.log for troubleshooting (it never contains messages or credentials). More options in the guide.

No publiques la dirección .onion de tu comunidad: compártela solo con quien deba entrar.

Don't publish your community's .onion address: share it only with people who should join.

Primer accesoFirst login

  1. Espera a que el estado pase de NEGOCIANDO TOR a TOR LISTO. La primera vez Tor puede tardar hasta 2 minutos en construir el circuito.
  2. Wait for the status to go from NEGOCIANDO TOR to TOR LISTO. The first time, Tor may take up to 2 minutes to build the circuit.
  3. Entra con el usuario y la contraseña inicial que te dio el administrador (por un canal privado).
  4. Sign in with the username and initial password your administrator gave you (over a private channel).
  5. El servidor pide PRIMER ACCESO: elige tu nombre y una contraseña de 12 a 128 caracteres (sin :). La contraseña nunca sale de tu equipo: solo se envían claves derivadas.
  6. The server asks for a first-login change (PRIMER ACCESO): pick your name and a 12 to 128 character password (no :). The password never leaves your device: only derived keys are sent.
  7. El cliente crea tu clave de identidad river_identity_<usuario>.key (cifrada con tu contraseña). Haz copia de seguridad: si la pierdes, se genera otra y tus contactos verán un aviso de cambio de clave.
  8. The client creates your identity key river_identity_<user>.key (encrypted with your password). Back it up: if you lose it a new one is generated and your contacts will see a key-change warning.

Compilar desde el códigoBuild from source

Necesitas un compilador C++17, CMake, GLFW, OpenGL y OpenSSL 3. En Debian/Ubuntu:

You need a C++17 compiler, CMake, GLFW, OpenGL and OpenSSL 3. On Debian/Ubuntu:

sudo apt-get install -y build-essential cmake libgl1-mesa-dev libglfw3-dev libssl-dev pkg-config
git clone https://github.com/jhulio435m/the_river
cd the_river/the_river_cpp
./build.sh

Produce the_river_server, the_river_client y the_river_admin. Para montar un servidor, sigue la guía del servidor.

It produces the_river_server, the_river_client and the_river_admin. To run a server, follow the server guide.
