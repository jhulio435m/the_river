Comandos del clienteClient commands

Escribe en el compositor usuario-->. Lo que no empieza por / va a la sala.

Type into the user--> composer. Anything not starting with / goes to the room.

AtajosShortcuts

  • ↑ / ↓ recuperan líneas enviadas antes.
  • ↑ / ↓ recall previously sent lines.
  • Tab completa nombres de usuario.
  • Tab completes nicknames.
  • Clic derecho sobre un usuario de la lista: Mensaje privado o Copiar nombre.
  • Right-click a user in the node list: Private message or Copy name.
  • Botón Adjuntar para enviar imágenes, vídeos o archivos (hasta 12 MiB); doble clic sobre un adjunto para abrirlo (un toque en la vista compacta).
  • Attach button to send images, videos or files (up to 12 MiB); double-click an attachment to open it (single tap in compact layout).
  • Botón EN/ES en la barra azul para cambiar el idioma de la interfaz.
  • EN/ES button in the blue bar switches the interface language.

Si se cae el enlace, el cliente vuelve a autenticarse solo con las credenciales de la sesión (guardadas únicamente en memoria). No lo hace tras un kick, un baneo, /logout o si la misma cuenta entra desde otra conexión.

If the link drops, the client re-authenticates on its own with the session credentials (kept in memory only). It does not after a kick, a ban, /logout, or when the same account signs in from another connection.

Variables de entornoEnvironment variables

Se leen del entorno o, si faltan, de tor_data/runtime.env / .env.local (carpeta actual o junto al ejecutable), una por línea en formato NOMBRE=valor.

They are read from the environment or, if missing, from tor_data/runtime.env / .env.local (current folder or next to the executable), one per line as NAME=value.

Nunca en el cliente

Never on clients

Con el protocolo 2 los clientes no usan THE_RIVER_AES_KEY. Si alguien te la pide para conectarte, desconfía. Tampoco compartas las contraseñas de arranque.

With protocol 2 clients do not use THE_RIVER_AES_KEY. If someone asks you for it in order to connect, be suspicious. Don't share the bootstrap passwords either.

Montar un servidorRunning a server

  1. Compila con ./build.sh en the_river_cpp/ (ver Compilar).
  2. Build with ./build.sh in the_river_cpp/ (see Build from source).
  3. Define los secretos en tu gestor de servicios o en un archivo privado, nunca en el repositorio.
  4. Set the secrets in your service manager or a private file, never in the repository.
  5. Configura un servicio oculto de Tor que apunte al puerto local del servidor (el cliente se conecta al puerto 80 del .onion).
  6. Configure a Tor hidden service pointing at the server's local port (clients connect to port 80 of the .onion).
  7. Arranca ./the_river_server, entra como admin, cambia la contraseña y crea cuentas con /newuser.
  8. Start ./the_river_server, sign in as admin, change the password and create accounts with /newuser.
# entorno del servidor / server environment (ejemplo / example)
export THE_RIVER_AES_KEY="$(openssl rand -hex 32)"   # guárdala / keep it
export THE_RIVER_ADMIN_BOOTSTRAP_PASSWORD="<cambia-esto>"
export THE_RIVER_NEW_USER_PASSWORD="<clave-inicial>"
./the_river_server

# torrc
HiddenServiceDir /var/lib/tor/the_river/
HiddenServicePort 80 127.0.0.1:8888
  • Guarda THE_RIVER_AES_KEY: si cambia, el historial sellado con la clave anterior deja de poder leerse.
  • Keep THE_RIVER_AES_KEY: if it changes, history sealed with the old key can no longer be read.
  • El directorio HiddenServiceDir contiene la clave privada del .onion. No lo subas a ningún repositorio; si se filtró, rota la dirección.
  • The HiddenServiceDir holds the .onion private key. Never commit it; if it leaked, rotate the address.
  • Al actualizar desde v1, las credenciales se migran a SCRAM en el primer arranque. Una fila que no pueda migrarse queda registrada y esa cuenta necesitará /passwd.
  • When upgrading from v1, credentials are migrated to SCRAM on first start. A row that cannot be migrated is logged and that account will need /passwd.

Consola de administraciónAdmin console

La consola the_river_admin se conecta como cualquier cliente, a través de Tor: necesita THE_RIVER_ONION y un proxy Tor local (puerto 9050 o THE_RIVER_TOR_PROXY_PORT). Ejecútala, introduce tus credenciales de admin y escribe /help.

The the_river_admin console connects like any client, through Tor: it needs THE_RIVER_ONION and a local Tor proxy (port 9050 or THE_RIVER_TOR_PROXY_PORT). Run it, enter your admin credentials and type /help.

cd the_river/the_river_cpp
THE_RIVER_ONION=<tu-direccion>.onion ./the_river_admin
