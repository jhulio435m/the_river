The River: un chat privado sobre Tor, con estética de BBS. The River: a private chat over Tor, BBS style.

Un proyecto de chat en C++17 que reúne un servidor como servicio oculto de Tor, un cliente gráfico ImGui y una consola de administración. Estas grabaciones muestran el prototipo funcionando en Linux.

A C++17 chat project with a Tor hidden-service server, an ImGui graphical client, and an admin console. These recordings show the prototype running on Linux.

Los mensajes privados y los adjuntos van cifrados de extremo a extremo; el inicio de sesión usa SCRAM, así que el servidor nunca guarda tu contraseña ni nada equivalente.

Private messages and attachments are end-to-end encrypted; login uses SCRAM, so the server never stores your password or anything equivalent to it.

Cómo funcionaHow it works

  • Servicio oculto de TorTor hidden service El servidor solo escucha en 127.0.0.1 y se publica como .onion. Los clientes llegan por un circuito Tor: nadie ve la IP del servidor ni la tuya. El cliente de escritorio trae Tor incluido. The server listens on 127.0.0.1 only and is published as a .onion. Clients arrive through a Tor circuit: nobody sees the server's IP or yours. The desktop client ships with Tor bundled.
  • Login SCRAMSCRAM login Autenticación mutua estilo SCRAM-SHA-256. La base de datos guarda claves derivadas, nunca la contraseña ni un hash que sirva para entrar. Mutual SCRAM-SHA-256 style authentication. The database keeps derived keys, never the password or a hash that could be replayed to log in.
  • Privados y adjuntos E2EE2E private messages and attachments Cada usuario tiene una clave X25519. Los /msg y los archivos se sellan con AES-256-GCM para el destinatario: el servidor solo reenvía sobres que no puede abrir. Each user has an X25519 key. /msg messages and files are sealed with AES-256-GCM for the recipient: the server only forwards envelopes it cannot open.
  • Huellas de claveKey fingerprints Las claves se fijan la primera vez que se ven (TOFU) y el cliente avisa si cambian. Compara /fingerprint con tu contacto por otro canal. Keys are pinned on first sight (TOFU) and the client warns when they change. Compare /fingerprint with your contact over another channel.
  • Historial y privados offlineHistory and offline PMs Al entrar recibes los últimos 100 mensajes de la sala. Los privados a alguien desconectado quedan en cola (cifrados) hasta 7 días. On login you get the latest 100 room messages. Private messages to someone offline are queued (still encrypted) for up to 7 days.
  • Consola de administraciónAdmin console Crear cuentas, expulsar, banear por usuario o HWID, anuncios y /whois con huella, desde the_river_admin. Create accounts, kick, ban by user or HWID, announcements and /whois with fingerprint, from the_river_admin.
  • Windows / Linux / Termux El código contempla clientes para Windows y Linux x86_64; en Android se compila dentro de Termux y corre en Termux:X11 con una vista compacta. The code includes clients for Windows and Linux x86_64; on Android it builds inside Termux and runs in Termux:X11 with a compact layout.
  • Retro a propósitoRetro on purpose Negro, azul BBS, magenta y lima. Comandos con /, historial con ↑/↓, autocompletado con Tab. Interfaz en español o inglés. Black, BBS blue, magenta and lime. Slash commands, ↑/↓ history, Tab completion. Spanish or English interface.
